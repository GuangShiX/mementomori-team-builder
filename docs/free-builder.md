# 自由配队 /free/

同站自由版使用独立计价策略与草稿，简易杯规则继续保留。两个入口共用精简角色目录、游戏美术和静态属性模块，不发布战斗技能、伤害或战斗执行代码。

- 玩家等级 1–1100，等级链接 1–1000；副等级为 0。只决定静态属性，不估算升级经验珠／潜能宝珠等投入，不计战斗技能临时增益。
- SR 来源每本体 17,000 钻；四色 LR/LR5 需 8/20 本体，光暗需 14/26。本体费用在配队与秘仪之间按角色 ID 的最高持有需求合并。
- R／N 来源本体不计价，不自动获得全目录持有；R 默认 LR5，N 保持 N。
- 装备制作碎片、专武制作、叶子、符石、红水、圣装按实际累计消耗全额折钻。魔装、绿水、金币免费，打磨不估随机费用。
- 没有免费角色或专武库、资源库存、恩泽、诅咒或武器同步制作优惠。付费借用同职业专武只计武器费用，不购买所属角色本体；一把一人，借用不获得自身专武技能。
- 普通符石以 Lv7 未鉴定符石 256 钻换算，每一级翻倍；穿透／速度单独按兑换券消耗。50 片 UR/LR 圣遗物装备碎片等价 2 个材料；10 片专武碎片等价 3 个紫水晶。换算只用于说明，不重复计费。
- 实际投入由纯计价模块输出，显示保留两位小数，不能当作玩家真实充值金额。

## 数据与导入导出

策略在 public/data/free-pricing-policy.json。free-levels.json 和 free-equipment.json 是选定角色成长、玩家等级及装备材料／属性的最小公开投影，按主表累计，不外推高等级成本；维护脚本 tools/sync-free-levels.py 不进入网站产物。原 450／560 投影保持兼容。

/free/ 共用站点根目录 data 和 assets，入口负责相对路径调整，避免复制游戏美术。自由草稿 key 为 mementomori-team-builder:free:draft:v1，与简易杯隔离。

沿用 mementomori-team-plan v1：自由方案在 team 记录 level 与 playerLevel，导出有效策略快照供查看。导入忽略输入策略、权益与报价，只按可信的当前自由规则重算；旧简易杯方案缺省玩家等级使用 560，去除旧同步来源且保留实际装备等级。不把可变等级支持声称为 5830 已接入。

参考价来源：https://hitazuki.github.io/mementomori-calculator/#packCompare 。普通符石默认依据公开源码 itemScores.json 的 Lv2=8 和 packCalc.js 的 Lv7 倍率32；当前核对版本 02df26557d9b8c73e420cd728271937920a099ef。
