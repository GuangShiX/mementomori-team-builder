# MementoMori 配队构筑器

供玩家配置五人队伍、查看资源等价钻石并导出 JSON 构筑方案的静态网站。浏览器自动保存草稿；文件通过玩家自己的联系方式发给构建方。无登录、自动上传、游戏请求或后台服务。

## 使用与发布

Node.js 24：`npm ci`、`npm test`、`npm run build`。本地开发使用 `npm run dev`，地址为 `http://127.0.0.1:5840/`。提交 main 后，GitHub Actions 自动构建并部署到 GitHub Pages；相对资源路径支持项目子目录。

角色共同链接等级暂固定为450。只列初始SR角色，可选择SR/LR/LR5；LR装备要求LR5，SSR专武最高240级。装备分为SSR撒旦、UR米迦勒、LR梅塔特隆。六槽各有四符石孔，攻击与防御符石依实际槽位限制，同一件装备不重复类别。穿透与速度允许1–15级；其余类别整队每类只提供3颗固定11级，不能额外购买。秘仪与玩家等级加成留给构建方采用统一基准，页面不展示推测战力。

## 管理计价变量

所有预算变量在 [`public/data/pricing-policy.json`](public/data/pricing-policy.json)。修改免费额度或单价时增加 `id`/`version`，重新发布即可；普通玩家不能在界面修改这些规则。当前450级整队默认：

| 项目 | 免费额度 | 超额或单位价格 |
| --- | ---: | ---: |
| 饼干／符石兑换券 | 100,000 | 10钻/个 |
| 红水／强化秘药 | 100,000 | 10钻/个 |
| 圣装经验等价 | 3,500份一级圣装 | 100钻/份 |
| 其它属性符石 | 每类3颗11级 | 不开放购买，整队共享固定库存 |
| SSR普通装备碎片 | 0 | 44.2470588235钻/片 |
| UR/LR普通装备碎片 | 0 | 211.4210142276钻/片 |
| 专武碎片 | 0 | 46.0676829268钻/片 |
| 叶子／生命树之露 | 0 | 400钻/枚 |

角色单本体17,000钻。SR=1本体；四色LR/LR5=8/20本体；光暗LR/LR5=14/26本体。每种资源独立扣除免费额度，余量不转移到其它资源池。圣装超额价格按一级经验约1000枚圣装钢×参考0.1钻制定；魔装只展示经验、不收费。金币、普通强化水、精炼钢、打磨和低价杂项未计入首版，报价是约定投入等价而非实际抽卡/交易保证。

圣装与魔装按累计经验计量：0级为0，L≥1为 `1+L×(L−1)/2`；40级=781。不会把四件10级当作一件40级。符石穿透与速度每颗L级为 `2^L` 饼干；其它类别按各自固定库存计数，不能兑换成穿透或速度，也不折算为未鉴定符石收费。最终钻石总额保留两位小数。

普通UR通过UR碎片直接制造，普通LR另需50叶子；UR专武累计15叶子，LR专武累计65叶子。SSR普通450级累计655片，UR/LR普通450级650片，UR/LR专武450级950片。强化450级每武器8418红水，其它每件4209红水。

## 配队文件与未来5830接入

导出格式 `mementomori-team-plan`，`schemaVersion:1`，保存目录版本、五人顺序、全部装备/符石参数、当前计价策略完整快照及费用明细。此文件是构筑计划，不是游戏账号快照。导入网站只接受已知结构并按本网站当前策略重新计价，忽略文件中声称的费用和策略。文件没有账号ID、令牌、私有路径或真实玩家数据。

纯计算模块 [`src/domain.mjs`](src/domain.mjs) 不依赖React、网络或私有模拟器，可用同样输入在其它系统调用。5830后续应采用管理员选定的策略重算费用，把计划转换为新模拟账号，并按本机职业、系列、等级解析内部装备和符石ID；秘仪与玩家等级基准由构建方提供。本站不声称已经实现5830导入或计算真实战斗。

## 数据来源

角色名、元素、职业与头像仅取自已公开的 [`GuangShiX/mmtm-assets-fallback`](https://github.com/GuangShiX/mmtm-assets-fallback)，头像按公开清单SHA-256验证并随静态站本地提供。`public/data/asset-lock.json` 锁定来源提交、路径与哈希；`node tools/sync-public-catalog.mjs` 是显式维护操作，不在玩家启动时联网更新。可通过环境变量 `ASSET_REF` 指定新的已公开提交，`PUBLIC_ASSET_CACHE` 指向该公开仓库本地缓存，缓存必须与清单哈希匹配。

价格参考 [`hitazuki/mementomori-calculator`](https://github.com/hitazuki/mementomori-calculator)：普通单价来自`src/constants/itemScores.json`，圣遗物/魔水晶/禁忌产品等价按`src/engine/derivedScores.js`与`gearCoreProductCalc.js`的默认抽取模型计算。圣遗物2个兑换50片；专武3魔水晶兑换10片。采用精简累计材料曲线，不复制整站代码、完整游戏主表或私有模拟器实现。

参考估值是本次固定的预算配置，后续不自动跟随第三方价格变化。角色目录版本与计价版本分别记录，以便复核。
